# Inherited generic-dimensional Morton

[morton_d_dim.cc](morton_d_dim.cc) and
[mortonplus_d_dim.hpp](mortonplus_d_dim.hpp) preserve the source project's
1–16 dimensional ball-reporting implementations. These files are not called
by the square runner, whose inputs are 2D squares or 3D cubes.

For active indexes, see the [2D](../2d/README.md) and [3D](../3d/README.md)
box interfaces. [Morton license](../LICENSE).
