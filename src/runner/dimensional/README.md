# Inherited dimensional disk runners

The C++, Rust and Python code here belongs to the original disk/sphere
benchmark. It illustrates the old ball-reporting contracts, file formats and
library integrations. It is not the square or cube execution path, and its
original build may depend on sources omitted from the public square copy.

For cube experiments, generate a `SQUARE1` case with `--dimension 3` using
the [case generator](../../../tools/README.md) and use the
[current build and runner](../../../README.md). Square/cube calls and the
exact-output oracle are in [src/square](../../square/README.md).
